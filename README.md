# 🎓 DERKAT PREMIUM REVISIONS - Student Management Portal

A modern web-based Student Management System designed for DERKAT PREMIUM REVISIONS.

## 📌 Features
- Student online registration
- Tutor login system (username + password + access code)
- Role-based access (Student & Tutor)
- Responsive design (mobile friendly)
- Ready for Google Sheets integration (database)
- Attendance & payment tracking structure (future upgrade)

## 👨‍🎓 Student Features
- Register online
- Login to dashboard (future upgrade)
- View academic information (future upgrade)

## 👨‍🏫 Tutor Features
- Secure login with access code
- Manage student records
- Attendance tracking (future upgrade)
- Payment tracking (future upgrade)

## ⚙️ Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub Pages (hosting)
